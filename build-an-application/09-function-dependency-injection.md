# 9. 関数引数で依存を差し替える

## 目的

レポート出力を題材に、出力先をグローバル状態や固定の標準出力にせず、`String -> IO ()` を関数引数として渡します。Haskellでは、必要な振る舞いを小さな関数型で表せる場合、専用のインターフェースやモック基盤なしに依存を分離できます。

## 最初のテスト

最初に、レポートが合計値を一つだけ出力することをテストします。テストでは `IORef` に書き込む手書きスパイを渡します。

```haskell
runReport spy [120, 80, 50]
readIORef messages `shouldBe` ["total=250"]
```

最初は `runReport` の未定義によるRedを確認します。次に、出力関数を一度だけ呼ぶ実装でGreenにし、計算と表示のロジックは既存の `renderTotal` へ委譲して重複をなくします。

## 完成実装

完成コードは `src/HaskellTdd/Report.hs`、テストは `test/Spec.hs` の「依存性注入」です。`Writer` は `String -> IO ()` の型別名であり、アプリケーション固有の最小依存を明示します。

## リファクタリングの問い

依存が一つの関数で足りる間は、複雑な抽象化を導入しません。設定、複数の出力操作、失敗の扱いが必要になった時点で、レコード型や型クラスを検討します。

## 次に増やす振る舞い

失敗する出力関数を渡したときに、`IOException` をどの境界で扱うかを仕様化してください。ドメインの計算は失敗に巻き込まれないよう純粋に保ちます。

## 実行

```bash
cabal test --offline
```
