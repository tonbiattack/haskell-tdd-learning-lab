# 5. 純粋関数とIOを分離する

## 目的

入力、計算、出力を一つの関数へ混ぜず、計算と表示を純粋関数へ切り出します。`main :: IO ()` はアプリケーションの境界に残し、業務ロジックはHspecで直接検証できる形にします。

## 最初のテスト

まず、合計計算を標準出力なしで検証します。

```haskell
calculateTotal [10, 20, 5] `shouldBe` 35
```

最小実装でGreenにした後、表示書式を別の純粋関数として追加します。`main` が文字列の生成や計算の詳細を持たないことを確認します。

## 完成実装

`src/HaskellTdd/PureIO.hs` の `calculateTotal` と `renderTotal` が純粋ロジックです。`app/Main.hs` はそれらを呼び出して標準出力へ書くだけです。テストは `test/Spec.hs` の「IOと純粋関数の分離」にあります。

## リファクタリングの問い

テストのたびに端末入出力を捕捉する必要があるなら、純粋な計算がIO関数へ混ざっている可能性があります。データ変換を関数へ取り出し、IOは値の取得と出力に限定します。
