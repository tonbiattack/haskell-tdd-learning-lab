# 6. QuickCheckで性質を書く

具体例が「この入力ではこうなる」を表すのに対し、QuickCheckは多くの生成入力で成り立つ性質を検証します。この教材では、独自reverseを2回適用すると元へ戻ることと、`findFirst` の返却値が述語を満たすことをテストします。

反例が見つかった場合は、生成された入力を小さく再現ケースへ固定し、まずHspecの具体例として追加します。その後、一般化できる性質をQuickCheckへ戻すと、具体例と普遍的な仕様の両方を保てます。

```bash
cabal test
```

発展課題は、ソート関数について「昇順」「要素数不変」「ソート後の要素集合不変」を記述することです。
